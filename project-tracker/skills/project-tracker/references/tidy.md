# Tidy-up on request

A sweep of the pages the user asks for, at the scope they name, and what any tidy-up does. Without such a request, pages are tidied one item at a time as the work goes (SKILL.md → **Keeping pages tidy**), each tidy-up as **What a tidy-up does** says.

Started by the user asking to tidy something: a task ("tidy TSK-7"), a milestone with its tasks ("tidy MLS-6"), a whole project. That is the request itself.

**Inputs:** the scope the user names, and each item's page, fetched fresh.

## Steps

1. Go item by item in the plan's order: the project page first when the scope is the project, then each milestone followed by its tasks, by `Order`.
2. On each item, look for the drift SKILL.md → **Keeping pages tidy** lists, and write its tidy-up as **What a tidy-up does** says, in the form SKILL.md gives.
3. Three items per reply, each item's tidy-up proposed and written on the user's yes (SKILL.md → **Propose, then write**), and say how many items are left: the user reads a sweep between other work, and three items is what one reply can carry.

## What a tidy-up does

Each kind of drift SKILL.md → **Keeping pages tidy** lists has one fix, so nothing is lost:

- the same thing in two parts → kept in the part whose question it answers (SKILL.md → **Pages**), dropped from the other;
- a history line carrying details that the description or a note holds → cut back to what happened;
- a note repeating the description → it keeps only what the description does not say;
- what the item consists of now, left in a note → moved to the description;
- a dated note that is really a history line, or one that becomes a subject note → its date kept in a history line (added if the history has none for it), so no date is lost; and a decision or result that only a note records gets its one history line too (`- **Oct 2** — Factory flashing at JLCPCB checked: left out of the plan.`), its details staying in the note;
- a file or picture stays where it is: these tools cannot move or remove a file block, so a misplaced one is only mentioned, for the user to move by hand.

A field or description that contradicts the history is not a tidy-up: ask about it at once, as SKILL.md says.

## Output

Each reply: up to three items' tidy-ups, proposed or written, and how many items are left.

## Off limits

Items outside the scope named; a tidy-up written without the user's yes to it.
